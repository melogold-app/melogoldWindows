Первая версия Melogold для Windows.

- Поиск по YouTube Music и обычному YouTube, «Тренды» и «Новое», альбомы, исполнители, каналы и плейлисты.
- Библиотека: Избранное, свои плейлисты, История, сохранённые альбомы и исполнители.
- Синхронизация с сервером Melogold: вход, регистрация, устройства; правки с телефона приходят за секунды.
- «Сейчас играет» с синхронным текстом, поиск текста по LRCLIB.
- Очередь, таймер сна, мини-плеер, медиаклавиши и кнопки на миниатюре в панели задач.
- Обновляется сама из GitHub.
