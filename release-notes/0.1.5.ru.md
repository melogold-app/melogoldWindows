- Сочетания клавиш: F1 или Ctrl+/ показывает все. Новые — перемотка Shift+←/→, перемешать Ctrl+H, повтор Ctrl+T, ♡ Ctrl+D, текст Ctrl+L, очередь Ctrl+Q, мини-плеер Ctrl+M, разделы Ctrl+1/2/3, а в редакторе текста — Backspace, стрелки и [ ].
- Обложки видео без чёрных полей: обложка сингла из видео-«статики» теперь квадратная.
- Плашка «Очередь заменена» всплывает поверх окна и больше его не сжимает.
- «Поделиться» в меню трека, правый клик по треку в панели плеера, громкость колесом мыши. Ссылку или файл копии можно перетащить в окно.
- В «Сейчас играет» нет второй стрелки «Свернуть», «Сведения о потоке» — только в «…» плеера.
