# Удалённое устройство не показывать в фильтре устройств

Статус: сделано — фильтр Истории и Итогов берёт только устройства аккаунта (`KnownDevices.Others`), список хранится по сеансу аккаунта на случай «без сети», `devices.updated` перечитывает его и возвращает фильтр к «Все устройства»; `HistoryDeviceOther` удалена, `tools/strings.tsv` снова совпадает с `.resw`; юнит-тест и живой тест на локальном сервере зелёные

Решение пользователя (2026-09-30): устройство, которого уже нет в аккаунте, в фильтре устройств **не показывается вовсе**. Не надо ни «Другое устройство», ни «Удалённое устройство»: пользователь его удалил, и строка без имени в списке только путает. Его прослушивания остаются в «Все устройства» — и в Истории, и в Итогах. Так уже сделано на Android (0.1.14) и Apple.

Сейчас Windows показывает такое устройство как «Другое устройство» (`CollectionPages.cs`, `ShowDevicesAsync`, строка `HistoryDeviceOther`). Это ошибка задания 0002 §3.5, не твоя.

## Что сделать

1. **Фильтр Истории** (`ShowDevicesAsync`) и фильтр Итогов (задание 0015, если он уже есть): в список попадают только устройства, чьи прослушивания есть здесь **и** которые есть в списке устройств аккаунта (`GET /auth/me/devices`). Остальные пропускаются.
2. **Фильтр виден**, только когда после этого остаётся хотя бы одно другое устройство. Если все чужие прослушивания — с удалённых устройств, фильтра нет, как без аккаунта.
3. **Без списка устройств** (нет сети, список ещё не приходил) имён нет — такие устройства тоже не показывать. Чтобы без сети фильтр не пропадал, храни последний полученный список (как Apple: в состоянии синка, по сеансу аккаунта) и бери его, пока свежего нет.
4. **Событие с сервера без `deviceId`** (хранится пустой строкой) в фильтре не выбирается: оно не «Это устройство» и видно только в «Все устройства».
5. **Если выбранное устройство удалили**, пока открыт экран (`devices.updated`), фильтр возвращается к «Все устройства».
6. Удали строку `HistoryDeviceOther` (оба `Resources.resw` и `tools/strings.tsv`), поправь комментарий у `ShowDevicesAsync` и задание 0002 §3.5.

## Проверка

- **Юнит-тест:** прослушивания трёх устройств, одно из них удалено из аккаунта → в фильтре два (это и оставшееся другое); все чужие удалены → фильтра нет; событие без `deviceId` в фильтре не появляется, но входит в «Все устройства».
- **На локальном сервере** (`melogoldServer`, `REGISTRATION=open`): войти вторым устройством, послушать трек, отозвать это устройство → на Windows после `devices.updated` оно пропадает из фильтра, прослушивание видно в «Все устройства».
