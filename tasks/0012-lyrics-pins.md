# Закреплённый текст песни: одинаковый на всех устройствах

Статус: открыто — ждёт сервер (`melogoldServer/tasks/0002-lyrics-pins.md`, контракт утверждён пользователем)

Те же задания: `melogoldAndroid/tasks/0013-lyrics-pins.md`, `melogoldiOSmacOS/tasks/0015-lyrics-pins.md`,
`melogoldLinux/tasks/0006-lyrics-pins.md`.

## 1. Что нужно пользователю

Найденный автоматически текст каждое устройство ищет само, и у одного трека на разных устройствах бывает разный текст.
Пользователь: «если включил песню и лирика правильная, ничего не делаю — значит, на другом устройстве должно быть так
же». Решение (2026-09-26): прослушал 30 с и не менял — текст закрепляется; сервер хранит ссылку на текст у поставщика.

## 2. Как должно быть (одинаково на всех клиентах)

- **Порядок выбора текста трека:** свой (набранный, из файла, выбранный в «Найти другой текст») → **закреплённый** →
  поиск, как сейчас (YouTube Music → LrcLib → KuGou; у видео LrcLib первым) → общий с сервера.
- **Закрепить:** трек проиграл 30 с (тот же момент, что запись в историю), текст найден автоматически, у трека ещё нет
  ни своего текста, ни закрепления. Устройство отправляет op `lyrics.pin.set` с `source`, `ref` и сдвигом «позже».
  Уже закреплённый текст не перезакрепляется: первое закрепление — общее для всех устройств.
- **Показать закреплённый:** достать текст у поставщика по ссылке (LrcLib — `GET /api/get/{id}`; YouTube Music —
  `browse` по `MPLYt…`; KuGou — `download?id=…&accesskey=…`) и сохранить у себя. Поставщик недоступен или текста по
  ссылке нет — обычный поиск; закрепление при этом не снимается.
- **Сдвиг «позже»** у закреплённого текста обновляет закрепление; «раньше» остаётся на устройстве.
- **Выбор в «Найти другой текст», правка, свой файл** — это свой текст (§4.10), он важнее закрепления.
- **Без поддержки на сервере** (`lyrics.pin.set` нет в `features.sync.kinds`) — всё как сейчас.
- Для этого у найденного текста нужно хранить **ссылку у поставщика** (id LrcLib, browseId YouTube Music, id и
  accesskey KuGou) — сейчас она после поиска теряется.

## 3. Windows

- `Melogold.InnerTube/Lyrics`: `LyricsFetcher`/`LyricsProviders` возвращают ссылку вместе с текстом и умеют достать
  текст по ссылке.
- `Melogold.Core/Data`: у найденного текста — `source_ref`; таблица закреплений (как у `likes`).
- `LyricsService`: порядок выбора (п. 2); закрепление — там, где пишется прослушивание в историю (30 с).
- `Melogold.Server/LibrarySync`: op и `lyricsPins` в ответе, `include.lyricsPins`.

## 4. Проверка

- Юнит-тесты: порядок выбора, «первое закрепление — общее», текст по ссылке для трёх поставщиков (фикстуры).
- Живой сервер (временный аккаунт): закрепление с одного «устройства» даёт тот же текст на другом, даже если поиск на
  нём нашёл бы другой.
