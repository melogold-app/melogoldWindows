# Клавиатура и список: F6 между областями, причина у недоступного трека, Esc

Статус: открыто

Из аудита `docs/design/AUDIT.md` (задание 0022).

## Что не так

- F6 и Shift+F6 по руководству Windows переключают между областями окна ([Keyboard interactions](https://learn.microsoft.com/windows/apps/develop/input/keyboard-interactions));
  у нас нет. Области: навигация, страница, панель воспроизведения, очередь (когда открыта).
- §4.2: недоступный трек приглушён (`MusicRow.TitleBrush`), но причины не видно — нужна подсказка и подпись диктору
  («Недоступно в YouTube Music» или причина, если она известна).
- Esc — «Назад» по страницам (`docs/PROMPT.md`) расходится с руководством Windows: Esc закрывает только временное.
  Записано исключением в `docs/design/EXCEPTIONS.md`; **решает пользователь** — оставить или вести назад только
  Alt+←, кнопкой и боковой кнопкой мыши.

## Проверка

- F6 по кругу: навигация → страница → панель воспроизведения → (очередь) → навигация; Shift+F6 — обратно.
- Наведение на недоступный трек — подсказка с причиной; диктор читает её вместе с названием.
- По Esc — решение пользователя записано в `EXCEPTIONS.md` (строка остаётся или удалена вместе с поведением).
