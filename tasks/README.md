# Задания

Всё, что нужно сделать в этом клиенте, лежит здесь: одно задание — один файл `NNNN-название.md`. В задании описано, что нужно пользователю, решение, контракт и проверка. Задания пишет пользователь или сессия, которая ведёт сервер и Android (Mac). Те же задания для Android лежат в `melogoldAndroid/tasks/`, чтобы клиенты вели себя одинаково.

## Как работать

1. В начале каждой сессии прочитай `docs/PROMPT.md` (основа клиента) и этот файл.
2. Выполняй открытые задания по номерам, сразу, без отдельной команды пользователя. Каждое задание — срез: сборка и тесты → запуск → скриншот → коммит → push.
3. Берёшь задание — поставь статус «в работе». Сделал — «сделано», в том же коммите, что и работа. Хэш в файл не пиши: свой хэш коммит знать не может, его находит `git log -- tasks/NNNN-*.md`.
4. Если в задании что-то не решено или противоречит коду, спроси пользователя, прежде чем делать. Контракт сервера не меняй сам.

Статусы: `открыто` · `в работе` · `сделано`.
