- "Download" in the track menu, like on Android: downloads are kept apart from the cache, never evicted and play without a network. A track already in the cache downloads at once.
- "Save as file": the track as an .m4a file with title, artist, album and artwork, with no quality loss.
- Row icons: downloaded — filled, cached — outlined, downloading — a ring with the percentage.
- Storage: fill bars for the caches, a clear description and a separate "Downloads" row.
- "Remove from history" also removes the track from "Most played" on all devices, like on Android.
